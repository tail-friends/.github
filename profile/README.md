# 꼬리친구 (Tail Friends)

내 파충류 사진으로 만든 캐릭터가 사육장에서 지내며, 실제 급여·탈피·체중 기록에 따라 상태를 알려주는 사육 기록 앱입니다.

## 왜 만드나요

파충류 사육자는 개체마다 급여일, 탈피, 체중을 따로 챙겨야 합니다. 꼬리친구는 이 기록을 한곳에 모으고, 다음 급여일과 건강 이상을 놓치지 않게 돕습니다.

기존 앱은 기록만 하거나(사육 기록 앱), 사진으로 캐릭터만 만들거나(사진 펫 앱) 둘 중 하나였습니다. 꼬리친구는 두 가지를 합쳤습니다. 사진으로 만든 2D 캐릭터가 사육장 안을 돌아다니다가, 실제 기록을 보고 "배고파요" 같은 말로 상태를 알려줍니다.

- **대상**: 파충류 1~10마리를 키우는 개인 사육자 (게코, 드래곤, 뱀, 거북)
- **범위 밖**: 커뮤니티, 분양 거래, 온습도 센서 연동

## 주요 기능 (1차 출시)

| 분류 | 기능 |
|---|---|
| 개체 | 개체 등록·수정·삭제 (이름, 종, 모프, 성별, 해칭일, 급여 주기) |
| 개체 | 종을 고르면 급여 주기, 체형, 기본 사육장이 자동으로 채워지는 종별 사육 계획 |
| 기록 | 급여 기록 (먹이 종류, 개수, 안 먹음 여부) |
| 기록 | 탈피 기록 (완탈 / 부분 탈피 / 블루 단계) |
| 기록 | 체중 기록과 그래프 (0.1g 단위, 직전 대비 증감) |
| 대시보드 | 다음 급여일 계산 (D-n / 오늘 / n일 지남) |
| 캐릭터 | 사진의 색·무늬·체형을 읽어 2D 일러스트 캐릭터 생성 |
| 사육장 | 사육장 테마 (사막, 열대우림, 바위 협곡, 달밤, 물가) |
| 건강 | 연속 거식, 체중 급감 시 경고 |

관리자 웹에서는 종과 사육 가이드를 관리하고 운영 통계를 확인합니다.

## 로드맵

| 차수 | 목표 |
|---|---|
| 1차 출시 | 기록 + 사진 캐릭터로 쓸 만한 앱 출시 (진행 중) |
| 2차 업데이트 | 매일 열게 만들기: 오늘 할 일, 일괄 기록, 캐릭터와 놀기, 케어 포인트, 기기 간 동기화, 사진 건강 체크 |
| 3차 업데이트 | 오래 키우는 사람을 위한 기능: 성장 앨범, 진료·번식 기록, 먹이 재고, 쿨링 모드, 위젯 |
| 4차 업데이트 | 캐릭터를 AI 실사풍으로 전환 |

## 레포지토리

| 레포 | 설명 | 기술 |
|---|---|---|
| [tail-server](https://github.com/tail-friends/tail-server) | 백엔드 API 서버 | Java 21, Spring Boot, PostgreSQL |
| [tail-app](https://github.com/tail-friends/tail-app) | 사용자 앱 | Flutter, Rive |
| [tail-client](https://github.com/tail-friends/tail-client) | 관리자 웹, 랜딩 페이지 | 미정 |

| 앱 | 사용자 앱 전체, 캐릭터·사육장 화면, 로컬 알림 |
